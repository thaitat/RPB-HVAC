HVAC Check - install on a smartphone

1. Upload every file in this folder (index.html, manifest.json, sw.js, icons/) to a GitHub repository.
2. Repository > Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
3. Open https://<username>.github.io/<repository>/ on the phone.
4. Android Chrome: menu (⋮) > Add to Home screen / Install app.
   iPhone Safari: Share > Add to Home Screen.

After changing index.html, edit VERSION in sw.js (e.g. hvac-check-v2) so phones get the new version.
